## Task 1
```Java
class Counter {
    int value = 0;
}

public class Main {
    public static void main(String[] args) throws Exception {
        for (int run = 1; run <= 5; run++) {
            Counter counter = new Counter();

            Runnable task = () -> {
                for (int i = 0; i < 1000000; i++) {
                    counter.value++;
                }
            };

            Thread t1 = new Thread(task);
            Thread t2 = new Thread(task);

            t1.start();
            t2.start();

            t1.join();
            t2.join();

            System.out.println("Run " + run + " | Final Counter: " + counter.value);
        }
    }
}
```

## Task 3
```Java
class Counter {
    int value = 0;
    synchronized void increment() {
        value++;
    }
}

public class Main {
    public static void main(String[] args) throws Exception {
        
        Counter counter = new Counter();
        int numberOfThreads = 5;
        Thread[] threads = new Thread[numberOfThreads];

        Runnable task = () -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();
            }
        };

        for (int i = 0; i < numberOfThreads; i++) {
            threads[i] = new Thread(task);
            threads[i].start();
        }

        for (int i = 0; i < numberOfThreads; i++) {
            threads[i].join();
        }

        System.out.println("Final Counter: " + counter.value);
        System.out.println("Expected Value: " + (numberOfThreads * 1000));
    }
}
```
## Task 4
```Java
public class Main {
    public static void main(String[] args) {

        Runnable task = () -> {
            for (int i = 1; i <= 5; i++) {
                System.out.println(Thread.currentThread().getName() + " : " + i);
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    System.out.println("Thread interrupted");
                }
            }
        };

        Thread t1 = new Thread(task, "Thread-1");
        Thread t2 = new Thread(task, "Thread-2");

        t1.start();
        t2.start();
    }
}
```
## Reflection Questions
```txt
Why does the incorrect result occur?
The incorrect result occurs because multiple threads perform the non-atomic "read-modify-write" operation simultaneously, causing them to overwrite each other's updates.

What is a race condition?
A race condition is a situation where the final outcome of a program depends on the unpredictable timing or sequence of thread execution.

Why does synchronized fix the issue?
The synchronized keyword enforces mutual exclusion by ensuring only one thread can access the critical section at a time using an object's lock.

Does more threads always mean faster execution?
No, because the overhead of context switching and thread management can outweigh the benefits of parallelism, especially when threads are competing for the same lock.
```
